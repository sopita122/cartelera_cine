# Lumenova Cinema

### Introducción
Lumenova Cinema consiste en una página web de cine, a la que las personas pueden acceder, elegir la película de su preferencia y hacer una reservación fictícia a su nombre (entrada).

### Materia
Laboratorio de Redes Informáticas

### Lenguajes utilizados
- PHP
- HTML
- CSS
- JavaScript

### Entornos utilizados
- XAMPP
- Visual Studio Code
