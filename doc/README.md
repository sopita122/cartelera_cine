# Introduccion: 
Lumenova es un proyecto web orientado al mundo del cine, desarrollado como parte de un proyecto académico que integra conocimientos de Diseño Web, Programación, Bases de Datos y Redes Informaticas.
La plataforma busca ofrecer una experiencia moderna e intuitiva para que los usuarios puedan explorar información relacionada con películas, funciones y contenido cinematográfico.
El concepto visual de Lumenova combina la temática del cine con pequeños elementos inspirados en el espacio, representando la idea de que cada película puede transportarnos a un universo diferente.


# Estado del proyecto : 
Actualmente, el proyecto se encuentra en proceso de diseño y desarrollo. Algunas funcionalidades pueden encontrarse incompletas o sujetas a cambios a medida que avance el trabajo.

# Objetivo
El objetivo principal de Lumenova es desarrollar una plataforma web relacionada con el cine que permita aplicar de manera práctica los conocimientos adquiridos en:
    - Diseño Web
    - Programación
    - Bases de Datos
    - Lab. Redes

Además, se busca crear una interfaz visualmente atractiva, sencilla de utilizar y coherente con la identidad de la plataforma.

# Características previstas
Entre las funcionalidades que se planea incorporar se encuentran:
    - Exploración de películas
    - Información de películas y funciones
    - Búsqueda y filtrado de contenido
    - Gestión de usuarios
    - Almacenamiento de información mediante una base de datos
    - Gestión de funciones o reservas
    - Interfaz adaptable a diferentes dispositivos

Algunas de estas ideas pueden ser modificadas o directamente no se implementen en el sitio.
